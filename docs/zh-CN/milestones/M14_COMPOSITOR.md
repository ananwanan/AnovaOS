# M14.3 用户态合成器契约

[English](../../en/milestones/M14_COMPOSITOR.md) | **简体中文**

该实验性原生 GUI 传输独立于冻结的 native v1 syscall、SDK 1.0.0、Linux 兼容层和 M14.4 GUI 库 C ABI。阶段状态见 [M14 GUI](M14_GUI.md) 与[当前状态](../guides/STATUS.md)。

## 隔离与权限

Rust `/bin/compositor` 是普通的隔离原生用户进程，其私有页保存窗口元数据、RGB surface 副本和软件屏幕缓冲。`crates/gui` 实现堆叠、焦点、移动、缩放、装饰、可见性、损伤区和输入目标；内核不实现这些策略。每个 GUI 客户端有独立用户地址空间。

可选内核 `gui` feature 增加实验性 syscall `0x100`；native v1 的 0–23 号含义保持不变。服务器准入将已加载可执行文件字节与不可变且显式命名的 compositor 引导模块比较。路径、参数、数据包字段和客户端 PID 均不能授予权限。fork 不复制准入或连接；成功 exec 重新检查准入并释放旧连接，失败则保留旧程序和资源。这属于可执行文件准入，并非通用文件权限或进程沙箱。

获准服务器独占显示和物理输入，每次绑定递增 session。最多允许四个经内核根据真实调用进程认证的客户端连接。每连接有一个最大 4,096 字节的待处理包和十六个 64 字节回复槽。服务器接收 envelope 包含真实 PID、session、生命周期类别及初始化后的负载长度；接收轮转处理各客户端。客户端不能读取其他连接回复或执行服务器操作。

队列非阻塞，满时返回 `WOULD_BLOCK`，客户端让出或睡眠后重试。客户端不消费回复而填满十六槽邮箱时，合成器通过仅服务器可用的 `DROP_CLIENT` 驱逐它，删除窗口和消息；客户端在显式重新连接前得到 `BROKEN_PIPE`，其他客户端继续工作。用户借用和活动用户页表不跨调度边界；分配均可失败，连接准入具有事务性。退出、硬件异常或成功 exec 关闭通道，断开 envelope 删除对应窗口。服务器死亡释放所有邮箱并将输入交还诊断消费者；旧客户端必须重新连接新 session，surface 不会自动恢复。

## 数据包、句柄与 surface 所有权

内部请求和回复均为 64 字节小端记录，字段宽度明确，检查版本/session 并拒绝保留字段非零。请求包括操作、序号、session、窗口、有符号位置、尺寸、像素 stride/count 和 flags。权限来自内核 envelope，而非不可信包字段。准确布局见 [`wire.rs`](../../../crates/gui/src/wire.rs) 与 [`transport.rs`](../../../crates/gui/src/transport.rs)。

每个客户端拥有一个 32×24 至 320×240、RGB u32 像素窗口。内部协议固定像素格式，无格式协商，仅保留低 24 位 RGB，忽略高字节，不做 alpha 混合。句柄含单调递增的世代号，并受 session 限定。异主/过期句柄、重复窗口、不支持操作、非法尺寸、长度/stride 不匹配或算术溢出在修改前拒绝。surface 存储属于合成器，不映射给客户端；进程无法获得物理显存地址或其他进程虚拟指针。

上传将整个已验证的有界矩形从包复制到私有 surface，确认后客户端即可复用源缓冲。各块独立提交，不提供跨包原子帧、密封协议、零复制共享 surface 或 GPU fence。`PRESENT` 标记窗口损伤；期间重绘可能看到已确认块。缩放清空私有 surface，客户端须重画。销毁、断开及重启使旧句柄失效并释放槽位。

## 软件合成与物理输入

合成器合并旧/新几何、遮挡、焦点装饰和光标足迹的损伤区，按堆叠顺序重画并仅提交该矩形。内核检查尺寸、目的位置、源 stride、指针范围和每个用户页，完整复制成功后才接触显存。usercopy 失败不改变设备。格式打包和 volatile 写入使用永久内核页表上的保留 supervisor RW/NX WC 映射，返回前执行 MFENCE；完成不表示 vblank、原子 scanout 或 page flip。

i8042 调度器轮询把物理键、绝对裁剪指针位置和按钮变化交给服务器，64 事件队列沿用 M14.2 重置语义。服务器绑定时隐藏内核诊断光标，由用户合成器绘制光标。焦点、标题拖动、缩放拖动和事件目标属于用户策略；重置取消按住状态和拖动。键盘事件仍是物理标识而非 Unicode。USB、硬件 IRQ 路由、键盘布局和 IME 不属于本阶段。

800×600 私有屏幕缓冲与四个最大 surface 共占 3,148,800 字节，保持既有 4 MiB 原生 ELF 内存上限；单线程进程 BSS 避免巨大用户栈。最大显示为 800×600，使用 standard-VGA framebuffer 进行 CPU 渲染。本阶段自身不交付 GPU 加速或公共 widget/SDK 库。

## 失败与验证边界

COM1 和原生 shell 独立于 GUI 进程。无 VGA/无 i8042 分别返回明确的不支持显示/输入错误。客户端异常不影响其他窗口；服务器异常失效全部连接，允许新进程和新 session。集成测试使用真实用户异常、独立进程及 QMP 物理输入，不以图片代替隔离证明。

`gui-test` feature 在调用生产邮箱连接准入前真实耗尽内核堆，要求 `NO_MEMORY`、无部分连接/泄漏，释放压力后准入恢复，并验证四客户端配额和最终精确堆恢复。这独立于普通 `gui` 镜像。准确执行命令、哈希、scanout 和回归范围见验收记录。

M14.4 已单独交付字体、控件、图形终端、剪贴板、版本化 C ABI 和独立 guest 构建的 C/C++/Rust 应用；M14.5 独立验证有界 GPU 清屏/读回及 fallback。物理硬件、SMP 和 Linux GUI 兼容仍需独立开发。
