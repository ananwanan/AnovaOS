# M14.1 软件显示验证

[English](../../en/validation/M14.1.md) | **简体中文**

本地验收 **2026-10-23（Asia/Shanghai）**。源码基线为 origin/dev 合并 M13 的 `1a36268`，开发分支 `codex/m14-framebuffer`，真实 checkout `/home/ananwanan/code/AnovaOS`；聊天挂载目录无代码。Ubuntu 24.04/WSL2、Rust/Cargo 1.90.0、QEMU 8.2.2 q35/TCG、单 `qemu64,+rdrand` CPU、256 MiB、锁定 OVMF/Limine 9.5.0。本历史记录不声明 remote CI/物理硬件，后续进度见[当前状态](../guides/STATUS.md)。

## 真实设备与恢复

`cargo xtask graphics-test` 退出 0，真实构建 graphics kernel/ISO，以 standard VGA 启动，经 QMP screendump 捕获 P6 并比较 **800×600 的 480,000 pixels**。独立 known pixels/字面量 FNV-1a RGB checksum 固定参考，避免 renderer/comparator 同错。

模式 800×600×32，pitch 3,200，canonical RGB checksum `0x9ed06ea9b3ba5f91`。volatile present/MFENCE 后逐 visible 字节回读，成功标记含 supervisor/NX/WC 检查；user 启动初期前释放 temp 缓冲区并报 `[GRAPHICS:RECLAIM] heap_restored=true`。

Limine framebuffer reservation 为 `0x80000000..0x801d4c00`，最终 page 部分覆盖。准入验实际 span，独立拒绝 page-rounded 与 live RAM/firmware overlap，mapped tail 不读写。首试保守拒绝有效 map 的失败保留在 `build/logs/graphics-initial-unrounded.serial.log`、`graphics-initial-unrounded.result.txt`、`m14-graphics-initial-unrounded.log`；最终门禁每次检查修正边界。

第二独立启动 `-vga none` 要求 `[GRAPHICS:FALLBACK] reason=no-framebuffer`、无 PRESENT、temp heap restored。两次启动均经 UART shell 执行 `echo M14-SERIAL-RECOVERY` 和关机，QEMU 0、`[POWER:OFF] synced=true clean=true dma_reset=true`。30 s watchdog 拒绝 hang，fatal/early/nonzero/missing-corrupt screenshot/bad checksum/fake 关机均失败。

`build/logs/` 保留：

- `graphics-test.result.txt`：aggregate 成功，每构建前失效旧结果。
- `graphics.result.txt`、`graphics-no-display.result.txt`：准确 invocation/mode/image/kernel 哈希、pixel count/checksum/shutdown/exit。
- `graphics{,-no-display}.serial.log`/`.qemu.log`/`.qmp.log`：真实 guest/QMP traffic，含 screendump request/关联 reply。
- `graphics.ppm`：真实 P6；SHA-256 `7311c0e55cd1ba490ff9c22fa764bfbcc2d64a5ad7617b15ddb11c4cc48a1d23`。
- `m14-graphics-command.log`：完整已验收命令输出。

验收 `build/images/anova-graphics.iso` SHA-256 为 `2c581fb8563fcd38a9be2e2a6682b9ae1b1bb2cd457714131f7c5151989ddbf2`，captured 内核为 `5eb980ab2e6827dba3510c799d1c90f091180e87d04b15024616973bbdaf81cd`。这是 local artifact，不是 path-independent 可重现性。后续普通构建覆盖共享目标 binary，不改变该 ISO/场景身份。

## 宿主边界与负例

无依赖 anova-graphics **19 宿主测试**：尺寸/caps、不支持 mask sizes/overlap/shifts/bpp、short pitch/overflow、RGB/BGR/所有 byte-channel permutation、24-bit packed/padded、valid non-byte-aligned 32-bit、哨兵、极端 signed coords、独立 rectangle/blit 参考、即使 fully clipped 仍修改前拒绝 bad 源码、short/mismatched present、pinned 图案。

五 host-tool 测试：strict P6 dimensions/format/header/raster 边界、raster whitespace、bad pixels/false 成功、timeout/fault/exit/shutdown rejection、真实 UnixStream QMP framing（async events/ID/errors/oversized messages）。QEMU 实测缺少显示；未另在运行 guest 注入 allocator 失败或 malformed hardware-mode/mapping fallback。

## 限制与当时下一阶段

M14.1 交付 CPU pixel/rectangle/blit 和 COM1，实际 device 仅 VGA 800×600×32，其他有界 RGB 仅宿主。无 vblank/page flip/tear-free 保证；显存 supervisor reserved，不入 RAM allocator/app API。本阶段无 GPU/font terminal/input dispatcher/window server/GUI SDK/new public ABI。当时下一步为 M14.2 input/cursor，M14.3–.5 独立门禁；后续验收看当前状态。`run --graphics` GTK manual preview 的 interactive GTK/WSLg 未在此测试。
