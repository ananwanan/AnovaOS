# M15.3 本地 GCC 可行性评估

[English](../../en/validation/M15.3.md) | **简体中文**

2026-10-24（Asia/Shanghai），feat/m15-bootstrap，base `be17906` 加报告所记 local 哈希。接受 [M15 GCC](../milestones/M15_GCC.md) 可复现实测及“当前无法重建 GCC”的结论。本记录不接受新 GCC stage/stage2/3/Rust-LLVM/kernel。历史本地记录，remote CI 独立，最新进度见[状态](../guides/STATUS.md)。

## 实际评估

bootstrap-gcc-test 两次 QEMU 8.2.2 q35/TCG、one CPU、1 GiB、no NIC；均 clean ACPI/flush/DMA 发行版，两 e2fsck 过。最终 build/logs/bootstrap-gcc.result.json 嵌 prepared/source audit，后续 prepare 不能改运行输入。逐启动 prefixes bootstrap-gcc-probe/reboot，configure 输出另 bootstrap-gcc-configure.log。

首次继承的 G++ 11.2.0 `-std=c++11 -O1` 编 seed.cpp static ELF，unique_ptr/vector/initializer-list/lambda 真实 42，只证明 seed app。gmp.h/mpfr.h/mpc.h 各真实编译器 status1/missing-header，无拒绝对象文件遗留，旧 seed 仍工作。

宿主诊断对 sed/awk/grep/expr/tr/sort/cmp/mv/ln 真实 execvp，每 child checked-pipe ENOENT/127。原 GCC configure 经 /linux/sh、显式 srcdir/triples、disabled bootstrap/multilib、C/C++ 选择，启动初期退出 1，六行日志仅缺少 sed/expr，无 missing-source-dir；未完整 configure/arithmetic link/compiler construction，启动初期 subset 明确省略后续输入。

容量仍验 >1 MiB EFBIG/bytes 保留的、EMFILE close/reopen、EAGAIN reap/new fork-wait，seed 再运行。第二次启动运行 persisted seed，全部 workspace 字节（upstream/notices/fixtures/ELF/configure output/空 .lineno）不变。

## 源码与容量证据

扫描 member 前核 ports/gcc/inputs.json 七官方哈希，不信 M11 extracted trees。整发行版 139,894 常规 files、922,827,305 logical 字节、至少 145,684 nodes、93 files>1 MiB；GCC 单独 108,258/620,324,686/65。含 optional tests/docs/其他目标，非最小编译器 closure/实测构建 demand。

普通 top-level Makefile.in=2,145,896 字节超当时可写上限，16 MiB/512-inode/2,048-node 无法导入整树，增 RAM 不解。逐发行版 counts/oversized paths/member 清单 hashes/provenance 在 audit。

本源码 selection/probes 保持格式/ABI/caps。scheduler 样本含刻意 exhaustion，max tasks/fd 不代表 GCC；frame 含内核、漏 syscall 瞬时、不是 RSS；wall 含 boot/shutdown，停盘非峰值。完整 GCC 构建未尝试，memory/time/storage 未测。
