## 实际 GUI 门禁

gui-test 三启 `graphics,gui,gui-test`：VGA+i8042、no VGA、no i8042。真实 UART shell 启 user supervisor `gui-test`，spawn Rust compositor 与独立 red/blue native 进程。合成器私有页管理 software surfaces/focus/move/resize/order/damage；内核仅认证 copied IPC/physical events/checked scanout，native v1/内存上限不变。

primary session 七张 800×600 screenshot **逐 pixel** 比较：overlap/red focus/move/resize/blue focus/red fault/fresh 服务器。QMP 真实 PS/2 movement/buttons/A/B/X/F11/F12。red `(80,80)`→`(160,130)`、`240x160`→`280x130`，blue 遮挡恢复。宿主独立 geometry/decorations 参考；宿主测试拒 bad background/window/cursor、malformed/duplicate 字段、wrong fault PID/vector、timeout/fatal。

X 在 focused red 执 UD2，只允许指定 PID/vector 6，须真实 wait status，窗口消失后 blue 仍接物理输入。F12 在第一 compositor UD2，全部连接失效；supervisor reap 真实 fault、启动新 server/client，宿主核 new session/identity/input。F11 正常结束重启 server/client。恰好两指定 faults，其他 fatal。

no-controller 启动显示双窗并完整比较另 480,000 pixels，然后测试服务器报缺少输入，supervisor reap；no-display 返回明确不支持，不假显示。三次启动均 COM1 恢复、clean ACPI、QEMU 0，90 s watchdog。共八图 **3,840,000 pixels**。

## 边界与恢复

- 未授权客户端不可 bind/receive server/input/present；空/超大 packet 和真实 bad 指针拒绝。
- wrong version/session、尺寸、stride、stale/foreign handles、duplicate surfaces 经真实 IPC 修改前拒绝。
- 四真实客户端填配额，第五拒；关闭回收后可 reconnect，无须服务器 restart。
- 不消费客户端填满十六 reply 被驱逐，其他不阻塞，再 reconnect；bad POLL 输出指针不消费 reply。
- 每启动真耗尽内核 heap、调 production connection allocation，要求 NO_MEMORY、无 partial/leak；释压后恢复、精确 heap 基线，与客户端配额压力分开。
- 十一 pure policy 测试：wire layouts/roundtrip、malformed 缓冲区、generation/session/owner、配额、私有 zeroing、damage/overlap/cursor、move/resize/capture/reset。不代替 native isolation/QMP。实际门禁验 destination/reconnect，按住的 reset/release 准确 QMP order 未另断言。
