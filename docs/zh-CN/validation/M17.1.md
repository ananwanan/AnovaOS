## 实现范围

- Rust `/bin/desktop` 管理一个合成器与三个已有、独立实现的 C/C++/Rust GUI 参考客户端。
  第四个连接/窗口归启动器使用。既有 GUI C ABI 和 native v1 记录保持不变。
- `init` 独立启动 COM1 shell，并等待任一子进程。shell 退出只重启 shell；
  桌面退出后串口恢复入口继续可用。默认启动方式不变。
- 启动器按钮或 `1`、`2`、`3` 启动/停止对应准入客户端；焦点和拖动沿用合成器。
  `r` 替换会话，`q` 退出；使用快捷键前先聚焦启动器。
  Stop 是立即以信号 15 终止，并非未保存提示或应用配合的正常关闭。
- 普通会话替换/退出会停止并回收自己管理的客户端和合成器，客户端退出报告真实原因/代码。
  合成器丢失会请求新会话；自动与手动重启共享进程生命周期内最多三次替换的限制。
  不修改持久文件；客户端缓冲区和 surface 重新创建，不自动恢复。
- 桌面布局根据可见矩形选择位置，忽略隐藏的 ABI 契约测试窗口。
  仍为四客户端/窗口，最大私有 surface 为 320×240。

## 进程边界

`crates/abi/src/process.rs` 定义独立实验系统调用 `0x101`。
RDI 为 `(version << 32) | operation`，RSI 为精确非零 PID；
POLL 的 RDX 为 16 字节 native `WaitStatus` 输出地址，STOP 则要求为零，版本为 1。
只允许操作调用者的直接子进程，PID 不复用；路径不会授予显示/输入权限。
Linux 调用者继续进入原有 Linux 分派器。

POLL 在原生子进程仍存活时返回 WOULD_BLOCK，不阻塞父进程；
退出后先复制状态再回收，非法输出地址保留 zombie。
STOP 对仍存在的 zombie 幂等，否则以信号 15 终止直接原生子进程。
存活的 Linux 子进程返回 UNSUPPORTED；已退出子进程沿用原生父进程既有 wait 状态语义。
同级、父级、间接后代和陈旧 PID 返回 NO_CHILD。
该接口不是全局任务观察器，也不会终止整棵进程树。

## 构建与启动

```sh
cargo xtask desktop-build
cargo xtask fetch
cargo xtask desktop-image
cargo xtask run --desktop
# 显式复用 native personality 工作盘：
cargo xtask run --desktop --disk build/disks/work.ext4
```

`desktop-build` 构建原生用户态、未修改的三语言 GUI 客户端和经检查的原生归档，
不下载 GCC/Rust Linux 种子配置。这些客户端由**宿主构建**，不构成新的 guest 编译证据。
产物和哈希位于 `build/desktop/`，镜像为 `build/images/anova-desktop.iso`。
`run --desktop` 只接受可选磁盘，使用 q35/TCG、单 BSP、3 GiB RAM、
800×600 标准 VGA/PS2 和 COM1；默认仍使用临时 ext2 盘。
显式桌面内核也准入已有的受控 ext4/JBD2 可写配置。

预计稳定会话包含七个进程：init、shell、监督器、合成器及三个客户端。
上限仍为 16 MiB 堆、32 任务槽、每进程 32 FD、128 打开对象、2,048 VFS 节点和四个私有窗口。
这些是声明的限制，不是实测桌面峰值，也不是桌面与构建并行验收。
