# M5 进程调度验证

[English](../../en/validation/M5.md) | **简体中文**

本记录保存原生进程调度、CPU/FPU 保留、阻塞、生命周期和回收的实测。日期为 2026-10-21（Asia/Shanghai），分支 `feat/m5-process-scheduler`，基于合并 M4 的 `dev` 提交 `9795803929c833569a87f9ec19c28d64caa09961`；引入此文件的提交标识实现。设计与准确 ABI 见 [M5_PROCESSES](../milestones/M5_PROCESSES.md)，后续进度见[状态](../guides/STATUS.md)。

## 宿主与输入

- x86_64 Ubuntu 24.04.3；Rust/Cargo 1.90.0、rustfmt 1.8.0-stable、Clippy 0.1.90。
- GCC 13.3.0、xorriso 1.5.6、QEMU 8.2.2（`1:8.2.2+ds-0ubuntu1.18`）。
- q35/TCG、qemu64、单 CPU、256 MiB，无网络或数据盘。
- Rust 组件取自官方 1.90.0 分发并按 channel manifest 验 SHA-256；QEMU/xorriso 经 apt 验证后解压到私有工具目录，由 wrapper 选择库/模块/firmware；仓库变更不依赖本地路径。
- bootloader/protocol/OVMF 身份和校验和仍锁在 `boot/dependencies.toml`，缓存经 doctor/image builder 检查。native ABI 和 ELF 精确哈希记录在生成的 `build/apps/manifest.toml` 并进入 ISO。

## 真实多进程启动

测试 ELF 启父进程与两个带不同寄存器值的 worker。各自进行三千万次无 syscall 的汇编循环，在真实 timer preemption 后检查 GPR、XMM0–15 的两个 64-bit lane、x87 stack/control、MXCSR。两个 worker 都打印保留成功。另一个 child 真实执行 UD2，父进程得到 reason=1/code=6，同时两个 worker 继续并退出 0；这需要真实硬件入口/状态保存，不能由模拟调度代替。

一次完整启动记录：

```text
[SCHED:TEST] preemptions=122 preempt_switches=97 switches=176 sleeps=4 waits=19 idle_halts=7 forks=2 execs=1 spawns=55 reaps=57
```

计数依时序变化。门禁要求至少两次抢占切换、真实 wait/sleep 阻塞和 idle HLT、至少两次 fork、一次成功 exec、55 次 spawn，reap 数等于 spawn+fork。六个用户场景标记各必须恰好一次：

| 场景 | 要求观察行为 |
| --- | --- |
| preemption-fpu-fault | child #UD 后两个保留 CPU/FPU 的 worker 仍完成 |
| fork-private-fd | child 看到复制内存、修改私有页且只关闭自身 stdout，父状态保持有效 |
| fork-cpu-state | fork 时 GPR/XMM/x87/MXCSR 带有效哨兵，两副本核验继承状态 |
| exec-reset-retain-fd | 新 image 的 BSS/FP controls 全新，先前关闭 stdout 仍关闭 |
| wait-any-orphan-repeat | wait-any、目标状态、重复 wait 拒绝、孤儿回收、16 次 create/wait |
| capacity-reuse | 父+31child 填满 32 槽，下个 spawn 失败，全部回收后新 child 成功 |


父进程还检查 unknown module、非法嵌套请求/输出指针、wrong layout size 和 sleep deadline overflow。C hello 独立执行 yield/sleep/close；本套件前 M4 应用、十一隔离用例、真实 copy-fault fixup 和八次重复 Rust 运行仍通过。

内核专门测试在 fork/exec/spawn 时把用户页预算限制三页，要求部分工作后返回 NO_MEMORY、精确恢复 frame/heap；旧 exec root 和已关闭 fd 不变，不发布 child slot。这是可重复预算 OOM，不是全 RAM 耗尽；M3 真耗尽/恢复仍在启动门禁中。

每完整会话在永久内核 root 销毁资源，free-frame/heap-use 等于会话前值、全部槽空、描述符所有权释放。分类器同时要求这些证据和 QEMU 33，缺失/篡改进程证据均拒绝。

## 边界与远端 CI

单 BSP、用户可抢占而内核不可抢占，每进程单线程、eager pages、固定上限，镜像来自 native module catalog。仅有无状态 console output 描述符，不含文件系统、输入 shell、持久化、Linux ABI、SMP、通用线程/信号/COW 或 guest compiler；sleep 使用已投递粗 timer tick。Actions 配置同样检查，远端结果/PR 随交付报告，不从本地成功推定。
