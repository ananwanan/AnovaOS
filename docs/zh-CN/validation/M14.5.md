## 渲染、边界与故障

每 healthy phase 验 7×5 `0x1280fe`/output-tail 哨兵，及四 64×64 red/blue/white/green。kernel/compositor 每 pixel 检查；四 backing pages 预填不同 per-pixel poison，无 CPU 参考 upload。真实 SUBMIT_3D/fenced TRANSFER_FROM_HOST_3D 后才比较。timeout/reset 后全重复，十次成功 GPU calls、32,838 readback pixels。

授权负例 pre-bind、zero/oversized/overflow 尺寸、非法 color/reserved、bad writable 指针、wrong request size；输出 sentinel 不变。真实非法 capset 返回 device `0x1205`；成功逐项验证 length/context/fence。

故障注入真实 publish 但抑制 doorbell，通过日志：

```text
[GPU:INJECT] lost_doorbell=true published=true
[GPU:TIMEOUT] watchdog=pm-timer deadline_ms=2000 reset_required=true reason=pm-timer elapsed_pm_ticks=7159195
[GPU:RESET] acknowledged=true dma_released=true
[GPU:RECLAIM] frames_restored=true heap_restored=true
[GPU:USER-FAILURE] timeout=true fallback=cpu
```

宿主必须看到 calibrated PM expiry，不是仅 iteration 上限；超时后验 CPU presentation，再起新 compositor 再得 hardware 输出。每成功 operation 重置后释放 DMA，frame/heap 精确恢复。reset-refusal quarantine 已实现/审查但未实际诱发。

五 800×600 QMP screenshot 对独立 CPU background+`(16,16)` green tile 逐 pixel：hardware、超时 CPU、recovered hardware、2D fallback、absent fallback，共 2,400,000 scanout pixels，各 SHA-256 `69803279e6f5df7617eecfe387fe759eb63f31165953ebce62fe6ce6831104f8`。准确 admitted compositor PID 在 completion 后/下一 prompt 前 0 退出；每启动真实 COM1 echo/clean ACPI/QEMU0。

初宿主门禁错在普通 interactive session 期待 scripted shell status 标记，改为关联真实 compositor PID/success exit，并有宿主测试覆盖 observed transcript、wrong PID/fault/nonzero/prompt order。修正后完整门禁通过。

## 延迟与 artifacts

十个 SUBMIT_3D+fenced readback interval **11.852–14.728 ms，中位 12.444 ms**，3,579,545 Hz ACPI PM。排 negotiation/context/resource/backing/reset/usercopy/VGA 复制，是 TCG/WSLg 小操作 latency，不是 throughput/desktop speedup。

`build/gpu/` 保存两个独立门禁结果；gpu-virgl.result.txt 记准确 command/host versions/renderer/ELF-ISO/screenshot hashes/recovery；各启动 serial/QEMU/QMP/results 记实际 device/process/shutdown/comparison。真实 scanout 为 gpu-virgl-render.ppm、gpu-virgl-timeout.ppm、gpu-virgl-recovered.ppm、gpu-two-dimensional-render.ppm、gpu-absent-render.ppm。

## 验收边界

仅接受该有界 hardware clear/fenced readback/CPU fallback。VGA presentation 和普通 composition 仍 CPU。不证明 shader、guest Mesa/GL/Vulkan、zero-copy、通用 GPU driver/passthrough/speedup/reset-refusal recovery/remote CI。CI 加 headless gate/two feature 检查，hardware 门禁须合适宿主显式运行。
