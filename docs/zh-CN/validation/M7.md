## 真实设备与文件系统

普通/测试镜像识别 PCI 00:02.0、1af4:1042，报告 32,768 sectors、八 split descriptors、一 DMA 页、modern VERSION_1/FLUSH/polled completion。末扇区可读，capacity/u64 overflow 在提交前拒绝，遵守 readonly features。

native fs-test 经 SYSCALL 验 dup/fork 共享 offset、跨第十二 direct block 写、sparse zero、seek/size、bad user buffers、fsync target、open-unlink/final-close/立即复用：

```text
[BLK:BOUNDS] last_sector=ok capacity=reject overflow=reject flush=ok
[DISK:MOUNT] /persist=ext2:rw profile=4k-single-group native=anova.native.v1
[DISK:TEST] offsets=true fork=true indirect=true sparse=true unlink=true reuse=true negatives=true
[BLK:RESET] acknowledged=true dma_released=true
```

normal smoke 必须有真实标记，拒 mount failure/DMA quarantine，整个 init/VFS/process 后 frame/heap 精确恢复。M2–M6 负例全留；十三场景保 success33、panic/OOM35、exception37、实际到达 timeout，既要求失败结果也要求正确注入诊断。

## 持久化场景

六场景均普通镜像、实际 COM1、无 test-exit，每 session 60 秒 watchdog。成功数据盘单独保 `build/disks/persistence-<unique>.ext2`，不与默认临时盘混淆。logs 为 build/logs/disk-*.serial.log/.qemu.log/.result.txt 和 persistence.result.txt。

| 场景 | 要求观察项 |
| --- | --- |
| disk-save | guest 磁盘 syscall；编辑器追加/替换/删除/打印/保存；fsync 成功；安装 ELF/native 退出 7；重定向/追加；真实正常 S5 退出 0 |
| disk-reboot | 重挂同盘，源码/文本准确；guest 内保存 ELF 逐字节匹配；tmpfs 文件丢失；保存程序再次退出 7；正常 S5 退出 0 |
| disk-read-only | 设备协商 RO；write 返回 READ_ONLY，原文本可读且正常关机成功 |
| disk-bad-feature | 未知 INCOMPAT 位以 INVALID_FILESYSTEM 拒挂；write 失败；initramfs shell 及关机仍工作 |
| disk-write-error | blkdebug write EIO 以 virtio1 完成；create/sync/retry/shutdown返回IO_ERROR，描述符仍可用、shell 状态 0 |
| disk-flush-error | attach 时 blkdebug FLUSH EIO/virtio1；拒挂、reset 释放 DMA、/persist 不可写，shell 仍可关机 |


最终 guest 编辑源码准确为：

```c
int main(void) { return 42; }
```

重定向 note 为 `durable\nappend\n`。前两次 boot 正常关机后宿主独立重挂 clean image，核 source/note bytes 和保存 ELF 对实际 C build 的 SHA-256：

```text
4c813fb2d7bc7007502d20fb9ea0146568db4a9daa90095f933bb2c148b38367
```

哈希标识本环境 C build，debug path 可改变。门禁从当前 ELF 动态计算预期，不硬编码。源码在 guest 编辑，ELF 是 host 编译后在 guest copy/install，不声称 guest compiler。

S5 成功要求停止所有 writers、final orphan close、实际 FLUSH、clean-superblock flush、确认 queue reset；仅 POWER:OFF 不够，还要求 QEMU 成功退出。错误场景不把失败 storage operation 算 durable success。

## 限制与未测路径

历史栈 64 KiB/heap2 MiB，ext2 scratch 用可失败 heap，一 coherent DMA32 frame 在 reset 前归 device，normal regression 验回收。两秒 timeout/failed-reset quarantine 已实现，但此验收未注入真实 stalled device 或永不 ACK reset。

无 journal、atomic save/rename、live recovery、通用 AML、hotplug、async block、device IRQ、SMP/Linux ABI/guest compiler。修改中强杀可损坏非日志 fs；拒 dirty images，须 offline recovery。editor 限 16 KiB ASCII/canonical serial lines。完整 geometry/fs cap 见设计；此 M7 change 未 remote Actions。
