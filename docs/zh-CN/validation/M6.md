## 真实 guest 行为

测试 init 为 PID 1，等待 fs-test ELF 和 shell script 后才退出。真实 native syscall 验证：

- 拒绝只读写、missing path、file/..、目录写、非法 fd、bad read/readdir/open/pipe 指针和 wire size；bad read/readdir 不改 offset，bad pipe 输出不发布 endpoints。
- 检查独立 open 与 dup/fork/spawn 共享 offset、exec 保留 fd 7、cwd 继承与 child chdir 隔离、打开数据在 unlink 后仍有效。
- 4,096-byte writer 超过 1 KiB pipe，父进程 sleep 时真实阻塞后正确 drain；reader 在延迟数据前阻塞、最终 writer EOF 后恢复；reader 关闭后 write 返回 BROKEN_PIPE。
- 填满 32 fd，失败 pipe/create 不留下新文件，close 恢复容量；128 次 create/write/unlink 复用节点；64 KiB tmpfs 文件拒绝越限写。
- 用多个 tmpfs 文件真正耗尽固定内核堆，write 返回 NO_MEMORY 且 offset 不动；close/unlink 后新 4 KiB write 成功。这不是人工预算注入。
- shell 列 mount/device，创建/读取/追加相对 tmpfs 文件、chdir、执行真实 Rust/C ELF、三段管道传 5,000 bytes，并隔离提前关闭的 reader；可见状态包括 0/7/127/1/syntax error 2。独立 ELF 读取核验 shell 输出文件。

接受启动包含以下标记（I/O counts 受调度影响）：

```text
[FS:CASE] paths-copy-offset-fork-exec-cwd passed=true
[FS:CASE] pipe-block-drain-eof-broken passed=true
[FS:CASE] limits-rollback-reuse passed=true
[FS:CASE] tmpfs-oom-rollback passed=true
[FS:TEST] passed=true
[SHELL:TEST] files=verified pipeline_bytes=5000 redirection=true cwd=true
[INIT:TEST] shell_status=0 children_reaped=true
[VFS:IO] blocks=21 wakes=21 open_descriptions=0 pipes=0
[VFS:READY] frames_restored=true heap_restored=true tmpfs=volatile
```

整个 init 结束后内核要求 free frames/heap 精确回到初值，live open descriptions/pipes 为零，并继续要求 M3/M4/M5 保护、CPU/FPU、回收、process capacity/lifecycle OOM。成功 QEMU 33，十二负镜像仍到达真实 panic/OOM/fault/timeout 并拒绝，分类结果写在各 result。

## 真实 UART 与全新启动

terminal-test 启普通镜像，等待 native prompt，经 QEMU serial stdin 输入；每会话 watchdog 30 秒：

1. 发送 echo tty-editX、DEL、CRLF，要求真实 tty-edit、backspace echo，不能因额外 LF 产生 syntax error。
2. 将 terminal-file 重定向到 `/tmp/terminal`，cat 核真实内容；Ctrl+D 后 init 必须重启 shell。
3. 观察成功后终止/回收临时 guest，再用同一不可变 ISO、新 OVMF variables 启第二 guest。
4. cat `/tmp/terminal` 必须 NOT_FOUND/status 1，Ctrl+D 再重启 shell；证明 tmpfs 丢失，并非磁盘持久化。

日志为 `build/logs/terminal*`、`terminal-reboot*`。普通 guest 无 debug-exit，仅在预期行为出现后由宿主终止；其余 logs/results 同在 build/logs 供 CI 上传。

## 限制与远端 CI

完整边界见 [M6_FILESYSTEM](../milestones/M6_FILESYSTEM.md)：单 BSP、有界内存挂载、native 单参数字符串 exec 和小型自有 shell，不声明可写持久化、Linux binaries、通用 mount/unmount、POSIX terminal、signals/threads/SMP/USB 或 guest compiler。

CI 配置 VFS/parser、13 regressions 和真实串口/两启动，但本批未远端运行。本地 artifacts 受 debug path/ISO time 影响，不承诺重新构建哈希相同。
