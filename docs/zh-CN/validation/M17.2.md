## 实际验收

`cargo xtask desktop-pty-test` 通过两次普通桌面内核的 QEMU 8.2.2 q35/TCG 启动：单
BSP、3 GiB RAM、800×600 VGA、PS/2、独立 COM1 shell，以及全新 64 MiB Linux
personality ext4/JBD2 工作盘。使用 Rust 1.90.0、musl 1.2.4、独立记录作业控制配置的
BusyBox 1.36.1、按既有 M11 配方源码构建的 GCC 11.2.0 和 e2fsprogs 1.47.0。不宣称
内核/编译器/镜像自举。

[保留证据](../../assets/validation/M17_PTY_LOCAL.json) 包含准确实现哈希、输入/工具身份、
完整成功 UART/TCP-QMP、命令/结果、停盘字节/哈希和压缩原始 QMP PPM。图像为真实
scanout，以独立字形/颜色采样验证，不是生成图片或全像素黄金图。`gzip_base64` 先经
Base64 再 gzip 解码，解压后 SHA-256 应与记录一致。

1. 打开终端前，`terminal check` 占满四组真实 PTY、拒绝第五组；检查畸形/地址/
   传输边界（版本解码单独由宿主测试覆盖）、外国创建者和过期 ID、读取复制失败保留、状态复制失败保留和 shell 实际
   状态 17。真实任务槽耗尽会拒绝 START 并回滚 master；原生 fork 持有者占满实际
   每进程/全局打开描述，释放后恢复 PTY 创建。
2. 物理启动器 `t` 将一个 GUI 客户端替换为原生终端。实际键盘启动
   `/linux/pty-fixture`，其 stdout/stderr 已知独立写入经 PTY 合流后分别显示为绿/红。
   下一命令将 `$?` 展开为 23 并呈现。没有从合流字节推断流身份。真实停止子进程的
   WUNTRACED/WNOHANG/继续执行探针呈现 `JOBS-OK`。
3. 物理退格将命令中的 `EDIT-X` 改为 `EDIT-Y`，重定向保存 `EDIT-Y\n`，COM1 独立
   重开。Linux 长任务呈现 `SPIN-READY`，存活期间 COM1 正常响应。物理 Ctrl+C 终止
   该前台子进程，shell 呈现 `INTERRUPT-130`。
4. 限速 600 行输出期间，以真实右下角拖动将 50×26 字符缩至 46×24。输出实际报告
   `WINCH-SEEN` 和 `SIZE ROWS=24 COLUMNS=46`。历史达到固定 256 行并记录淘汰数，
   Shift-PgUp/PgDn 实际浏览/返回；保留的 C GUI 同伴继续收到物理输入。
5. 物理 Ctrl+D 产生真实 EOF/shell 退出，F5 创建严格更新的会话。经图形键盘输入
   `/bin/gcc /etc/terminal-hello.c -o /persist/pty-app` 编译实际源码，报告 `BUILD-0`，
   `/persist/pty-app` 呈现 `M17-COMPILED`/`RUN-7`。另一探针 fork 后代并调用 setsid；
   从启动器停止其原生创建者，关闭并回收全族，再次启动成功。F4 关闭替换后的终端。
6. 再次 `terminal check` 得到 25 个空任务槽，初始为 24：原第三 GUI 客户端现已不在，
   没有遗留终端、shell 或脱离会话的子进程。每次压力检查最后连续创建/关闭四次会话，
   堆、空闲帧、打开描述和管道采样与各自 START 前快照完全一致。
7. 正常退出会话/关机、独立 e2fsck、普通重启、图形重开和图形运行同一已保存程序
   全部通过。两次停盘转储的工作文件、程序和 ABI 标记字节一致，未更改挂载 personality。

## 发现并修复的问题

整窗同步 GUI 上传会挤满输入事件队列，丢失快速输入命令的开头。终端现每次只异步
上传一个需确认的块，确认之间处理键盘和 PTY。像素快照在 PRESENT 前保持不变，
几何变化使旧帧失效。shell 最初因作业等待不支持 WUNTRACED 而返回 255；实际子进程
停止通知、成功复制后消费及阻塞等待唤醒现已补齐该实测需求。

宿主驱动也有两项观测缺陷：真实鼠标可遮住采样字形；从已前移 UART 光标等待会漏掉
已记录的缩放。现将鼠标停在终端外，并使用操作前记录位置。GUI 同伴坐标取其实际
窗口记录，不假定启动顺序。重启会清除未结束的 ANSI 字符串，避免旧输出隐藏新 shell。 脱离会话探针现等待 setsid 成功后的管道握手，并使用已验收的 nanosleep；先前反复调用未实现 pause 的原始 UART 观测单独保留。

宿主缺少完整 M11 安装树，本次使用校验锁定输入运行未修改的既有配方。musl 主下载
返回 503，Buildroot 镜像提供完全相同的锁定 SHA-256。隔离验证的 Ubuntu m4 包及按
已校验 bootstrap 归档恢复可执行权限补齐了宿主前置条件。这是宿主构建已有 guest
种子，不是 guest 编译器自举。
