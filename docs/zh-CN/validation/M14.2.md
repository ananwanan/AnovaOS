## 真实 controller、注入事件与 scanout

`input-test` 启 graphics,input-test image，QMP `input-send-event`/`send-key` 经真实 i8042/PS/2，不以直接调用 decoder 证明输入。

controller 明确 set-1/translation disabled，mouse 重置 ID 0、relative three-byte、1:1 scaling。初始化查 interface/self-test/reply source/ACK-RESEND/ID；100 ms ACPI PM deadline+独立有限 attempt，最多三 retry。IRQ1/12 和其他 device IRQ 屏蔽；permanent root scheduler 每 pass 最多 64 bytes/64 事件，IRQ 不访问设备/光标、不 alloc/log。

常规配置验十一 ordered physical-key transitions：A press/repeat/release、extended Right press/release、Shift+A press/release 的 modifier set/clear、B press/release（send-key）；物理键不注 COM1 text。另验 movement 和 left/right/middle press/release。

五张真实 P6，每张比较全部 **480,000 pixels**：cursor `(410,307)`、`(0,0)`、`(799,0)`、`(0,599)`、`(799,599)`，检查 clipping/旧 footprint 完全恢复。7×9 arrow 有独立 pinned raster；固定 63-pixel save area 保存 unused channels 在内 device 字节，无 full-screen 保留的 allocation。保留 supervisor RW/NX WC map，MFENCE 排 WC stores。首次指针才显示 cursor，保留 M14.1 pattern/heap reclaim。

两个负启动 `-vga none` 与 `-machine i8042=off`：前者无 cursor 仍测 key/motion/三 buttons，后者要求 INPUT:FALLBACK 并拒 READY。每启动执行 `echo M14-INPUT-SERIAL-RECOVERY`，clean ACPI `[POWER:OFF] synced=true clean=true dma_reset=true`、QEMU 0。60 s watchdog；fatal、healthy-path 意外重置、early/nonzero、wrong scanout 均失败。

## 恢复负例边界

input-test 在 consumer READY 前真实验证：

- 实际 64-event dispatcher overflow 丢 history/trigger、清按住的 keys/buttons、发 Reset。
- malformed mouse 头文件不虚构 motion。
- 诊断 detach/reconnect 丢断开输入，下次 make 是 fresh press。
- 禁用真实两个 i8042 ports 后重跑完整初始化，两个 device 均恢复再收 QMP。
- keyboard/mouse 部分独立超时，含 PM wrap，late continuation 前失效；peer traffic 不延长过期，100 ms interbyte 由 PM 轮询采样，不依赖 IF-masked LAPIC tick。

产生 `[INPUT:SELFTEST]`/`[INPUT:TIMEOUT-TEST]`。这是 guest 状态/lifecycle 注入，不证明 QMP wire overflow、物理 unplug/hotplug 或 live compositor crash。healthy QMP 另证恢复后物理 delivery。三字节 PS/2 无法总识别丢包；controller errors/expiry 重置两 decoder。

anova-input **22 宿主测试** 含 make/repeat/break、双侧 modifiers、Caps/Pause/PrintScreen/SysRq/fake shifts、malformed、signed nine-bit extremes、buttons/overflow/framing/source-independent reset/clipping、queue capacity/wrap/overflow/reconnect。graphics pin cursor；宿主门禁拒 bad background/cursor、坐标、缺事件字段、timeout/guest 失败。
