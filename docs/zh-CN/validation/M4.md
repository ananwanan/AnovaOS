# M4 原生应用验证

[English](../../en/validation/M4.md) | **简体中文**

本记录描述隔离原生应用的验收及限制。日期为 2026-10-21（Asia/Shanghai），分支 `feat/m4-user-apps`，基于已合并 M3 的 `dev` 提交 `3d7d42b0e416b2019d7b55410b87ac7b045e593c`，引入本文件的提交标识完整实现。这是历史本地证据，最新进度见[当前状态](../guides/STATUS.md)。

## 环境与输入

- x86_64 Ubuntu 24.04.3，锁定 Rust/Cargo 1.90.0，含 rustfmt/Clippy。
- rustfmt 1.8.0-stable、Clippy 0.1.90、GCC 13.3.0（`13.3.0-6ubuntu2~24.04`）。
- QEMU 8.2.2（`1:8.2.2+ds-0ubuntu1.18`），q35/TCG、qemu64、256 MiB、单 CPU。
- QEMU/xorriso 经 apt 验证后解压到临时私有工具目录，wrapper 只选择库、QEMU 模块及 firmware；内核/runner 源码不变。
- Limine 9.5.0 二进制提交、protocol、OVMF 2024.02-2ubuntu0.9 及全部输入哈希仍锁定于 `boot/dependencies.toml`，由 `cargo xtask fetch` 核验。
- 应用 ELF、显式 `anova.native.v1` personality 和 SHA-256 记录于生成的 `build/apps/manifest.toml` 并复制进 ISO。

## 真实用户态结果

通过镜像在 CPL3 运行 Rust/C ELF，均打印真实参数并验证零初始化 BSS/SSE2；Rust 另验 x87/default FPU control。真实 SYSCALL 后分别退出 0/7，随后内核执行探针并核精确结果：

| 场景 | 实际要求结果 |
| --- | --- |
| syscalls | unknown syscall、bad fd/size、null/kernel/noncanonical/overflow/cross-guard 指针、可写跨页 query、DF-on-entry 检查后退出 0 |
| timer | Ring 3 接收真实 IRQ 并观察 coarse tick 变化后退出 0 |
| page-fault | 用户 #PF，error0x4，CR2=0 |
| kernel-read | 用户 #PF，error0x5，CR2=0xffffffff80000000 |
| kernel-write | 用户 #PF，error0x7，同一 supervisor 地址 |
| stack-guard | 用户 #PF，error0x4，CR2=0x7ffffffdffff |
| invalid-opcode | 用户 #UD，vector6/error0 |
| privileged | 用户 CLI 触发 #GP，vector13/error0 |
| bad-rsp | SYSCALL 安全进入可信栈，RSP=-1 的返回被拒绝 |
| read-only | 真实写 probe text 触发用户 #PF/error0x7 |
| no-execute | 真实调用不可执行 data 触发用户 #PF/error0x15 |


每次执行后完整回收私有页、页表和内核栈，再运行下一例。将用户页分配预算限制为三页会在部分加载时 OOM，并精确恢复 frame count；这是刻意预算注入，不称耗尽全部 RAM，M3 的真实全页耗尽仍保留。畸形 ELF、PIE、错误 personality 和嵌入 NUL 参数在执行前拒绝。

两个刻意 copy-site 异常分别在 unmapped `0x10000` 验读/写 fixup，独立于预检查，模拟页表检查后访问时撤销；此阶段还没有并发 unmap。窄 fixup 返回错误，内核继续执行。额外八次 Rust 应用验证 fresh BSS/FPU 和稳定页数；用户 IRQ 真实投递，计数为正且写入日志，数值依时序而变。

12 个既有负例均到真实注入点：panic/OOM 退出 35、fatal kernel fault 37、controlled hang 超时，不因早期 banner 就通过。成功启动要求完整 M2/M3/M4 阶段和 QEMU 33。

## artifacts 与边界

`build/logs/` 保存各例 serial/QEMU/classified result 和普通镜像记录，CI 上传同目录。准确 ELF hashes 在 `build/apps/manifest.toml`，下表仅标识本次本地字节；调试路径/ISO 时间戳可变，不构成可重现承诺。

M4 一次只运行一个顺序 native 进程，未实现/验证调度、保存 FPU 任务上下文、并发 unmap、文件系统/输入、持久化、Linux ABI、SMP 或实机。宿主构建应用在 guest 运行，不等于 guest 中运行 GCC/Rust/Cargo。远端 CI 另行报告。
