## guest 构建与应用门禁

`gui-sdk-test` 同一 native ext2 volume 上构建启动+clean 重启通过。COM1 line editor 保存七份准确源码：C/C++/Rust 客户端、ABI probe、caller-fault probe、Rust note、interactive Rust terminal。真实 guest GCC/G++ 编独立 freestanding 对象文件；rustc 编无依赖运行时 rlib/Rust 对象文件，再用 native CRT/intrinsics/panic 链接全部。宿主仅打包 source/已验编译器，无宿主 GUI ELF 替代；immutable ABI 标记为 anova.native.v1。

每语言客户端单独开窗口、渲染 text/primitives/widgets，物理 a 输入 textfield、真实 button click，q close。C++ 另测 move ctor/assignment、RAII destruction、moved-from/stale。note 将编辑文本复制到显式 process-local clipboard 并核字节。

terminal 在 GUI 前建 helper，真实执行 `/bin/echo`，支持 echo TEXT/pwd。QMP 逐 key 输入 echo hi，等待字段 ACK、Enter，核真实 hi 输出 pixels；native command/pipe/wait 均真实，close reap helper。无 PTY/job control/ANSI。

**28 张真实 screenshot** 用独立字面量 palette/border/textfield/original glyph 样本，不调用 production renderer 造 expected。三语言 initial/text/click 完整 SHA-256 相同，每 phase 重启前后相同；该采样不是 full-screen pixel 比较，完整 composition 由 M14.3 独立负责。

每启动七 client/server pairs 各有唯一 PIDs/真实 wait。bad GUI 输出指针写 unmapped `0x1000`，精确指定客户端 #PF vector14/reason1/code14，其他 faults 拒。随后普通 C 客户端仍工作，证明恢复。F11 停 compositor，全 child reap，serial recovery/两 QEMU 0/clean shutdown/两 e2fsck 通过。

构建后 editor 真追加 `#error` 到 C，编译器 status1/真实诊断，旧 ELF 字节不变，再移除该行。七 sources/七解析后 native ELFs/旧 C ELF 重启哈希相同，第二次启动不重新编译。

## ABI、所有权与宿主检查

生成 C 头文件 asserts size/alignment/offset；guest C/C++/Rust 验 negotiation/by-value rect。负例 wrong version/description size、UTF-8/text limits/color bits/small buffer/layout exhaustion/单窗口 quota/stale-reused generation/double destroy。运行时无 heap，其 LIMIT 是 fixed-storage 容量，不冒充真 heap OOM；保留 M14.3 真内核 heap exhaustion/rollback。

16 运行时宿主测试含 raster guards/clipping/glyph、UTF-8/backspace/capacity atomicity、lifecycle/chunk completeness/ordered events/overflow RESET、resize+overflow geometry/interrupted present-redraw、keys/modifiers/repeat/release、malformed/disconnect/remote stale/session。完整宿主 suite **182 测试**；另三宿主门禁测试验 identity/wait/fatal/timeout/恰一指定 fault。pure 测试与 guest scheduling/physical delivery/isolation 分开。

SDK inventory/生成头文件通过，workspace 外独立 SDK 复制自清单跑 16 测试。root/user/standalone fmt、302-file 用途、local links/diff 检查过，unsafe/source 所有权单独审查。完整门禁后 gui-sdk-replay 用最终宿主驱动又启保留的输出，原 ISO/source/ELF 哈希必须一致，terminal RENDERED ACK 后才截一次输出，七场景/全部哈希保留；`build/gui-sdk/replay.result.txt` 为结果=Ok。
