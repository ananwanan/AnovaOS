## Linux 宿主对照

三个 runtime 配置均在 native Linux 直接通过，含畸形 rt_sigreturn child、SIGILL group exit、thread exec/identity、wait status 和 PTY 前台信号。输出保存在 `build/logs/m9-native-*.out`。同一二进制还经 QEMU-user syscall trace，结果位于 `build/logs/compat-host-m9-*`。

此环境禁止 native ptrace，QEMU-user trace 只用作 syscall 观察，不替代所有 child 的 native strace；同架构 exec 可能离开 QEMU-user，native 执行补充完整最终进程/退出结果。

保留两项明确对照限制：

- Linux 可允许 W+X，AnovaOS 刻意拒绝。M9_HOST 仅为对照选择该宿主策略，guest 门禁仍要求 EACCES。
- QEMU-user 8.2.2 在刻意畸形 sigreturn 时内部 abort，只有此宿主仿真子例标为 unavailable，并有独立 HOST marker。native Linux 与 system QEMU 均执行该用例，guest 无条件要求 bad_sigreturn=true；失败 trace 保存在 `build/logs/m9-qemu-user-bad-sigreturn.trace`。

shared-close 样例使用 fd 20，避开 QEMU-user 在 target close 后内部复用低宿主 fd，仍检查真实 CLONE_FILES 跨线程 close；先前观察保留于 m9-qemu-user-fd-reuse.trace。观察 syscall 包括 clone、futex WAIT/WAKE/REQUEUE、mprotect、sigaction/masks、rt_sigreturn、poll/ppoll、ioctl、setsid、tkill/kill、fork/exec、wait4，推动实现真实 REQUEUE，而非成功 stub。

## 真实 guest 验收

三个独立 Ring 3 程序各自运行完整负载，内核和宿主分类器要求成功退出及准确清理：

| 范围 | 要求实际结果 |
| --- | --- |
| pthread/TLS | 两个 worker、私有编译器 TLS、mutex/condition 同步、1,000 次受检递增、join 值及共享 fd close |
| futex/shared pages | 值不符、对齐和超时错误；真实 wait/wake/requeue；fork MAP_SHARED 数据及跨进程 futex |
| 信号 ABI | 真实用户 handler、siginfo sender 和 rt_sigreturn；恢复 handler 改动的 XMM7，检查 EINTR 和 SA_RESTART 管道读取 |
| mask/时间 | 阻塞信号保持 pending，ppoll 临时 mask 恢复，nanosleep 中断后剩余时间为正 |
| 就绪状态 | 非阻塞空管道返回 EAGAIN，有限超时、child 写入唤醒、EOF/HUP 和非法 fd 的 NVAL |
| 线程生命周期 | 非 leader exec 获 leader 身份，重置捕获 action；缺 interpreter 返回 ENOENT 且调用者存活；SIGILL 终止组，检查线程 exit_group 和畸形 sigreturn 状态 |
| 停止/继续 | 子进程自行停止，父进程发送 SIGCONT，子进程恢复后成功 wait |
| PTY/termios | 真实 master/slave、初始 lock 拒绝、canonical 行和 echo、raw 字节、输出 poll、前台 Ctrl+C、peer close EIO |
| 动态运行时 | 真实 musl PT_INTERP、启动 shared library、创建 worker 后 dlopen、逐线程动态 TLS 初始化及明确缺失库名的错误 |
| 保护 | PROT_NONE 保留 backing，mprotect 启用选定 data 页，拒绝 W+X，unmap 成功 |
| 回收 | 每个程序恢复物理页和堆，tasks/open-descriptions/pipes 均为零 |


共享所有权元数据另有真实耗尽测试：可失败分配逐步耗尽 2 MiB 内核堆至最小 block，fork/exec/spawn 返回 NO_MEMORY，旧 root/fd 保留、部分资源全部回滚，释放压力后 heap/frame 精确恢复。这检验实际可失败 Shared，不仅依赖页预算注入；两个宿主测试另验单次最终析构、唯一可变访问和 allocator 返回 null 的路径。

## 回归契约

普通启动必须 isa-debug-exit33，panic/OOM35，真实异常 37 并匹配注入、向量、IST、错误位和地址。超时必须到 TEST:HANG 后才由 watchdog 结束，firmware/startup timeout 不满足负例。

最初八秒限制在本 M9 环境可能尚未进入内核就到期。verify 现所有场景（含刻意 hang）均用有界 30 秒，保留真实注入检查；未到注入的八秒日志保留于 m9-timeout-8s-unreached.serial.log。多镜像只构建一次用户态，复用前重新核验不可变构建快照，变化则失败，不静默复用。

本历史范围不包括 SMP、通用 Linux/glibc、完整 terminal jobs、alternate signal stacks、robust/PI futex、realtime signal queue、COW、持久文件 mmap、网络或 guest compiler。当时下一里程碑为 M10，后续能力由独立记录验收。
