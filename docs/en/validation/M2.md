## Limits and next task

Only the BSP exception/timer baseline is accepted. All external IRQ sources stay
masked; routing overrides/NMIs and device delivery remain untested. IST3 is
installed but actual NMI/machine-check delivery was not exercised. Time is a
coarse delivered-IRQ count and can lag while IF=0. No memory is reclaimed and
there is no allocator, user process or scheduling. M3 must establish explicit
memory ownership before replacing the retained boot stack/tables or adding a
frame allocator and heap. See [M2_CPU.md](../milestones/M2_CPU.md).
