## Executed local gate

`cargo xtask bootstrap-test` completed three QEMU 8.2.2 q35/TCG boots with one
CPU, 1 GiB RAM and no NIC. Every boot reached real clean ACPI poweroff with
successful disk flush and DMA reset. Read-only `e2fsck -f -n` was clean after
each boot. The generated final report is `build/logs/bootstrap.result.json`;
full serial/QEMU evidence and per-boot result files use `bootstrap-capacity`,
`bootstrap-build` and `bootstrap-reboot` under `build/logs/`.

The official bzip2 1.0.8 archive SHA-256 is
`ab5a03176ee106d3f0fa90e381da478ddae405918153cca248e682cd0c4a2269`.
Both it and the pinned official SHA-512 are checked before selecting unchanged
source files. The persisted source workspace contains 26 files and 912,093
logical bytes, including the recipe, source manifest, negative fixture,
notices and official samples. No host-built bzip2 is supplied. The separate
host-built capacity executable is a diagnostic fixture only.

The first boot rejected a persistent resize beyond 1 MiB with `EFBIG` and
retained the exact prior file bytes and length. It opened 29 additional
file descriptors before `EMFILE`, then closed and reopened successfully.
It created 29 blocked children before `EAGAIN`, released and reaped them all,
and proved another fork/wait succeeds. Including init/shell/probe, sampled
live tasks and occupied slots reached 32 and descriptor use reached 32.
The probe scratch file was removed. These forced maxima are separate from
ordinary build measurements.

The second boot invoked guest make/GCC/cc1/as/collect2/ld to compile eight C
objects and link `/persist/bootstrap/bzip2`. Compression with block size 1
produced bytes identical to official `sample1.bz2`; guest decompression
matched `sample1.ref`. Python independently decoded the persisted stream.
Testing README as compressed input produced the actual bad-magic diagnostic
and status 2. The full guest output is retained, including optional unsupported
`madvise`/`sysinfo` probes; their `ENOSYS` responses are not fabricated success.

The third boot ran the persisted compressor, then invoked the real compiler
on `rejected.c`. GCC reached `#error M15_intentional_build_rejection`, returned
1, and make returned 2. The prior compressor still tested its saved stream
successfully. All 37 persisted workspace files, including source, recipe,
objects, ELF and compression results, matched the preceding hashes exactly.
This proves the controlled syntax-rejection path, not transactional recovery
from an arbitrary interrupted linker or power failure.

The work disk retains 4,096 blocks of 4 KiB and 512 inodes (16 MiB).
After build and reboot it uses 377 allocated blocks (1,544,192 bytes) and

is excluded; the HTML manual and all compiled source units are retained.
