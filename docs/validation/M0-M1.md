## Acceptance boundary

M0/M1 are locally accepted on this QEMU profile. CI is configured; remote job
execution is reported separately. WSL2, KVM, physical hardware, Secure Boot,
missing-framebuffer firmware configurations and external modules were not run.
No exception handler, allocator, owned page tables, user process, persistent
filesystem, network stack or Linux compatibility is claimed. RSDP reporting does
not validate ACPI tables. All boot data remains retained for M2/M3.
